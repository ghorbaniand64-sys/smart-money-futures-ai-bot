HYPERLIQUID TRADER HUNTER V3
READ-ONLY. No orders/private keys.

Keep all existing V2 Monitor variables.

ADD in Environment=production:
HYPERLIQUID_HUNTER_DISCOVERY_ENABLED=true
HYPERLIQUID_HUNTER_DISCOVERY_URL=https://stats-data.hyperliquid.xyz/Mainnet/leaderboard
HYPERLIQUID_HUNTER_CANDIDATES=
HYPERLIQUID_HUNTER_LOOKBACK_DAYS=7
HYPERLIQUID_HUNTER_MAX_CANDIDATES=300
HYPERLIQUID_HUNTER_MIN_7D_TRADES=30
HYPERLIQUID_HUNTER_MIN_7D_WIN_RATE=65
HYPERLIQUID_HUNTER_MIN_7D_PNL=0
HYPERLIQUID_HUNTER_MIN_PROFIT_FACTOR=1.5
HYPERLIQUID_HUNTER_MAX_MEDIAN_HOLD_HOURS=6
HYPERLIQUID_HUNTER_MAX_AVG_HOLD_HOURS=12
HYPERLIQUID_HUNTER_MIN_ACTIVE_DAYS=4
HYPERLIQUID_HUNTER_MAX_LOSING_STREAK=8
HYPERLIQUID_HUNTER_MAX_LIQUIDATIONS=1
HYPERLIQUID_HUNTER_STATE_FILE=state/hyperliquid_trader_hunter_v3.json

The discovery endpoint is a public stats-data leaderboard, separate from the official Info API; its shape can change. If unavailable, the Hunter falls back to HYPERLIQUID_HUNTER_CANDIDATES and HYPERLIQUID_TRADERS.

Run:
GitHub Actions -> Hyperliquid Trader Hunter V3 -> Run workflow
