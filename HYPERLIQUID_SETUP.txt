V5 CHANGES
----------
1. Discovery reads only leaderboardRows[].ethAddress; no recursive 0x extraction.
2. Every failed trader scan is logged with an error category.
3. 429/5xx/network failures retry with exponential backoff.
4. userFillsByTime uses aggregateByTime=false and overlapping pagination with deduplication.
5. Telegram separates discovered, candidates, successful scans, failures, filter blocks and selected traders.
6. Current position/book/1H candle calls happen only after statistical filters pass.
7. Read-only: no order/private-key/execution code.
8. Hyperliquid's userFillsByTime data is finite; very active accounts can have incomplete history. V5 flags long scans as HISTORY_TRUNCATED.
