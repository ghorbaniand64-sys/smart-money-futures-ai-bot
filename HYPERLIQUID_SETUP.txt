TELEGRAM REPORT:
The report includes:
- selected trader address
- 7D closed trades
- win rate
- realized PnL
- profit factor
- median/average/P25/P75 hold statistics in state
- active days
- trades per active day
- max losing streak
- liquidation count
- reason for selection
- source open position
- source entry
- current market mid
- entry distance
- source leverage as information only
- source unrealized PnL
- planned entry
- planned SL
- planned TP
- planned RR
- planned maximum holding time
- COPY PLAN eligibility/block reason

IMPORTANT:
Entry/SL/TP/RR are a READ-ONLY planning layer. They are NOT source trader TP/SL and this version sends NO orders.

The source trader's leverage is informational only. It is NOT copied as execution leverage.

Run:
GitHub Actions -> Hyperliquid Trader Hunter V4 -> Run workflow
